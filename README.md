

# Jarvis – BFMC 2026

This repository contains the project work for the Bosch Future Mobility Challenge (BFMC) 2026.

## Repository Structure
- monitoring: Project plan and system architecture
- Project status: Monthly reports and progress videos
- src: Source code for perception and autonomy modules

## Current Status
- Manual control achieved
- Stop sign detection tested using YOLOv5 in development environment
- Stop sign handling logic integrated at software level

## Future Work
- Integration with BFMC vehicle camera
- Closed-loop autonomous control
